# Bj Beyond Scanner
Website Opportunity Analysis Chrome Extension

## Features
- 5-category website analysis (SEO, Conversion, Trust, Technical, UX)
- Shopify detection
- AI-powered recommendations
- Freemium pricing: Free (5 scans/day), Pro (€7.99/mo), Agency (€19.99/mo)

## Project Structure
- bj-extension/ - Chrome extension
- bj-scanner-backend/ - Express API backend
- bj-scanner-landing/ - Landing page
